Unified icons · 1000 × 1000 square

Built on top of the simplified set. Every icon is wrapped in a transform that re-centers its content into a 1000×1000 square with a 5 % margin. Content bbox is computed from the actual path geometry, not the declared viewBox — so portrait, landscape and oddly-cropped sources all end up in the same canvas, optically centered.

All unified icons stacked on the same square at 18 % opacity, multiplied.
