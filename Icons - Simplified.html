Sheet B · Filesize reduction

Simplified SVG icons

Same shapes, fewer bytes. Decimals on path coordinates rounded to one place, the sub-pixel seam-stroke layer dropped, the opaque white background rect removed, and all whitespace and redundant attributes collapsed. No paths re-drawn — visually equivalent at every icon size the set is used at.

01
Drop the seam-stroke layer
The top-level <g stroke-width="2"> only draws thin anti-alias seams between adjacent filled regions. Invisible at marker size.
≈ 30–40 % saved
02
Round coordinates · 1 decimal
Source paths have 2-decimal precision over a ~1200-unit canvas. At 110 px hero size, 1 decimal = ~0.01 px — undetectable.
≈ 20 % saved
03
Drop white background rect
A full-canvas fill="#ffffff" rectangle covered every icon. Removed so icons are transparent and composite cleanly into marker pins.
marker fidelity win
04
Strip noise
Collapse &#xA; newlines and whitespace inside d=, remove vector-effect attrs, drop the XML prolog.
≈ 5 % saved
